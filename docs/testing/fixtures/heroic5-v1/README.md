## 装备和材料

- 每人 17 槽、均 ilvl 200；固定显式物品 ID，不走随机/BIS 补高装等。
- 主要从早期英雄副本掉落表筛选；防骑圣契 40707、元素图腾 40708 为 ilvl 200 商人物品，ExtendedCost=2525（DBC 核验为 15 枚 item40752 英雄纹章）。不含团本套装、冠军试炼、ICC 三本或高装等装备。
- 宝石为早期蓝色品质，附魔不使用专业专属收益；专业未指定，不宣称满专业。
- 全员指定 71 点天赋模板、六雕文和关键技能。防骑要求实际防御技能至少 535；这是入场装备检查，不代替承伤实测。
- Supplies 补充毒药、祝福/祷言/奥术材料、四系图腾/十字章及普通食物饮水（每项一叠，上限20）。材料不足会阻断开怪，不自动清除失败证据。
- [ITEMS.json](ITEMS.json) 保存每个槽位的物品、名字、装等、来源、附魔和宝石。配置位于模块 conf/mod-raidtest-roster-heroic5-v1.conf.dist；运行时必须核对安装后的 .conf。

## 运行口径

新场景 requireNoCheats（蓝图 RequireNoCheats=true）检查全局与逐 bot 掩码的按位或为零；实际 playerbots.conf 应设 `AiPlayerbot.BotCheats = ""`。它不是“底层所有辅助行为已消除”的证明，还需按 boss 审计。

角色快照新增 effective_cheats、defense_skill、max_health 和 supply 记录；装备指纹加入 supply_item（种类），不加入消耗后变化的库存数量。cheat/难度须另外关联运行配置，不能只比角色指纹。

五人小队没有团本专用显式主坦旗标（核心 SetGroupMemberFlag 仅支持 raid）；因此保留普通小队，由底层识别防骑坦克职责，入场检查坦克识别。不要为了旗标把五人本队伍转成团队。
