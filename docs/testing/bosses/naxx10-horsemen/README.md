# 纳克萨玛斯 10 人 / 天启四骑士 / `naxx10-horsemen-r10g`

## 接手摘要

- **2026-09-29：5/5 稳定击杀（1764–1768，232–272 秒，死亡 1–4 人）**。
- 阵容换成 **`raid10-ilvl200-v1-resto`**（只把槽位 8 平衡德换成恢复德，四骑士专用；其余 boss 仍用 v1）。用户同意：血 DK 独守男爵撑不到科尔塔兹倒下后再换治疗，并权衡萨满。
- 代码：playerbots `6264e868`（按编号找骑士）、`17815355`（共享层：正义防御不救另一名坦克）、`6d095444`（10 人前排两坦 / 吸引者 / 副坦治疗）；raidtest `0d2c86c`（议会型遭遇的开怪门槛与卡住判定）、`63fb757`（开怪不计脚本走位、开怪前就位、阵容）。

## 机制（核心脚本 + Spell.dbc 实测）

- 开战后四人进入被动、沿路点走到各自角落，到终点才变主动、`SetInCombatWithZone`，并按仇恨选目标；技能计时（含印记）在到角落后才开始走。
- 印记：前排（科尔塔兹 28832、里文戴尔 28834）**半径 55 码**、每 12 秒；后排（女士 28833、泽里克 28835）**半径 45 码**、每 15 秒；持续 25 秒；每层伤害 0 / 500 / 1500 / 4000 / 12500 / 20000。
- 后排：对最近的玩家施放暗影箭 / 神圣之锤；45 码内没人就对全团放无尽痛苦 / 审判（审判是早期灭团主因，40 秒 24–27 万）。女士在目标脚下放虚空区域。
- 前排两个角落相距 59.7 码；泽里克与女士角落相距 70.3 码。

## 打法（对应真人 10 人打法）

1. **开怪前就位**（`SlotPreparation`）：主坦在台阶上（14 码，保证视线）；副坦血 DK 在里文戴尔的角落；副坦治疗（戒律牧）在治疗点（离男爵角落 35 码、离主坦点 30 码）；两个吸引者（恢复德、猎人）在后排各自的点。
2. **第一阶段（科尔塔兹活着）**：副坦把男爵拉在他自己的角落（男爵走来时原地等，被别人拿走就嘲讽回来）；主坦把科尔塔兹拉到角落内 5 码；远程站在科尔塔兹身后 5 码。全团只叠科尔塔兹的印记（他约 63–67 秒倒下，约 3 层）。
3. **第二阶段**：主坦（男爵印记 ≤1 层）在副坦 ≥3 层时嘲讽男爵；被换下的坦克、以及任何叠到 4 层的非坦克，去房间里离男爵最远的已知安全点，等印记整层消失再回来。全团转火男爵。
4. **后排**：两名吸引者在泽里克–女士连线上的两个点（离泽里克 21 码、离女士 24 码，互不进对方 45 码印记，彼此 25 码可以互奶），按时间轮换；只允许为站位和躲 AoE 移动；虚空区域落在点上时改站最近的、仍满足印记分隔的空地。前排死后非吸引者治疗和全团走到女士、再到泽里克。
