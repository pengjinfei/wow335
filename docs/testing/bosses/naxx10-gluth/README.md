## 失败原因（run 1556 / 1557）

| run | 结果 | 时长 | boss 最低 | 说明 |
|---|---|---|---|---|
| 1556 | wipe | 368 s | 19% | 格拉斯吃了 **37 只僵尸**（每只回 5%，共 185%）；全队对他 19k dps。6 分钟狂暴团灭 |
| 1557 | wipe | 219 s | 63% | 吃了 22 只；主坦 134 秒死亡后崩 |

1. **僵尸没人拉（主因）**：playerbots 格拉斯策略的僵尸由 `IsAssistTankOfIndex(bot, 1)`（第二副坦）风筝，猎人截冲向 boss 的僵尸，其他远程只打 ≤10% 的僵尸（残杀后）。10 人双坦阵容里第二副坦不存在，DK 是第一副坦（和主坦一起坦格拉斯、负责致死之伤换坦）。僵尸 10 人血量系数 40（约 50 万），不能逐只打掉，只能风筝 + 残杀后群伤。若一只不被吃，1556 按总伤害约 140 秒可击杀。
2. **换坦抢嘲讽**：DK 在主坦致死之伤 ≥5 层时嘲讽，主坦立刻抢回（1556：DK 黑暗命令 21 次，主坦清算之手 18 次、正义防御 14 次）。`GluthGenericMultiplier` 在主坦 ≥5 层时屏蔽的嘲讽列表里没有**正义防御**（31789）。
