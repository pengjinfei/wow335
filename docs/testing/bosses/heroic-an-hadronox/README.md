## 为什么是隔离形态

完整遭遇战的开场是打上层平台的粉碎者包：`npc_anub_ar_crusher::DoEngagedWith` →
`hadronox->DoAction(ACTION_CRUSHER_ENGAGED)` → `SetBossState(IN_PROGRESS)` → 再召 2/3 号包 →
她按 45 秒/70 秒分三段爬上平台并织门（`SPELL_WEB_FRONT_DOORS`）。

这三个包是她 `Reset()` 时 `SummonCreatureGroup` 出来的**召唤物，spawnId = 0**，
而 mod-raidtest 的 `PrerequisiteSpawns` 只接受数据库 spawn 的 guid
（`AttemptRunner` 用 `map->GetCreatureBySpawnIdStore()` 查）。**当前框架无法表达。**

本场景改为直接在坑底拉她。**保留的**：穿刺护甲(53418)、吸血毒(53030/59417)、
酸液云(53400/**59419**)、蛛网猛拉(53406/**59420**)、以及三扇门的持续刷怪
（世界触发器在 `Reset()` 时就带上了周期召唤光环，与是否打粉碎者包无关）。
**缺的**：三个粉碎者包、以及「她爬上平台」那一段。

`WotlkDungeonANStrategy::InitTriggers` 里哈多诺克斯**一条触发器都没有**，源码注释写
「核心那几个 trigger 对这个 boss 很不稳，默认策略看起来能打」——实测不能。

修复方向（mod-playerbots）：给她加「被蛛网猛拉后重新拉开距离」与「离开酸液云」两个触发器。
和魔枢的经验一致：先量化再写策略。

## 本轮扫清的阻塞

跑通这个场景前必须先修掉两个缺陷，都已修好并验证（详见 [台账](../../BOSS-LEDGER.md)）：

1. 核心 `CreatureGroup::DespawnFormation` 遍历中释放迭代器节点 → 段错误崩溃。
2. mod-raidtest `ResetInstance` 对带 `CREATURE_FLAG_EXTRA_HARD_RESET` 的 boss 失效
   （`CreatureAI::EnterEvadeMode` 末尾会 `DespawnOnEvade()` 把 boss 直接下线）。
   哈多诺克斯英雄 entry 31611 的 `flags_extra = 0x80000001` 带这个标志。
   修复后日志会打 `spawn 127401 was hard-reset on evade - reloaded as guid ...`。
