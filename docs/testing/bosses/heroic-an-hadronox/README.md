## 为什么是隔离形态

完整遭遇战的开场是打上层平台的粉碎者包：`npc_anub_ar_crusher::DoEngagedWith` →
`hadronox->DoAction(ACTION_CRUSHER_ENGAGED)` → `SetBossState(IN_PROGRESS)` → 再召 2/3 号包 →
她按 45 秒/70 秒分三段爬上平台并织门（`SPELL_WEB_FRONT_DOORS`）。

这三个包是她 `Reset()` 时 `SummonCreatureGroup` 出来的**召唤物，spawnId = 0**，
而 mod-raidtest 的 `PrerequisiteSpawns` 只接受数据库 spawn 的 guid
（`AttemptRunner` 用 `map->GetCreatureBySpawnIdStore()` 查）。**当前框架无法表达。**

本场景改为直接在坑底拉她。**保留的**：穿刺护甲(53418)、吸血毒(53030/59417)、
酸液云(53400/**59419**)、蛛网猛拉(53406/**59420**)、以及三扇门的持续刷怪
（世界触发器在 `Reset()` 时就带上了周期召唤光环，与是否打粉碎者包无关）。
**缺的**：三个粉碎者包、以及「她爬上平台」那一段。

## 2026-09-24 第 7 条：酸液云（MasterlessAvoidAoe）

- **量化（ilvl 200 完整形态基线 run877–881）**：boss 伤害按数值分桶，酸液云（59419：5 码、90 秒持续、≈1414/秒）占各非坦克承伤 47–75%，非坦克合计约 161 跳/场；吸血毒 59417（25 码、1000/秒×10 秒）主要落在坦克与近战；蛛网猛拉 59420 伤害仅 2.4%。
- **根因**：mod-playerbots `AiFactory::AddDefaultCombatStrategies` 只在 `HasGameClientMaster()` 时加 `avoid aoe`；raidtest 全 bot 队伍从未启用通用躲 AoE（`AutoAvoidAoe=1`、`MaxAoeAvoidRadius=15` 本身都满足）。
- **变量**：raidtest 场景开关 `MasterlessAvoidAoe=1`（开怪前在战斗引擎加 `+avoid aoe` 并回读，5/5 生效）。
- **结果 run882–886：1/5 kill**——882 kill（476.169s，1 死）；883 前 87 秒坦克/萨满/治疗先后阵亡、事件复位后法师独活拖到 540s timeout；884 wipe（73%）；885 wipe（77%）；886 540s timeout（boss 66%，坦克与治疗仍存活）。
- **执行门槛通过**：非坦克酸液云跳数 16/0/93/30/…（基线 ≈161/场）；每场平均承伤治疗 47k→18k、盗贼 73k→51k、萨满 74k→52k（近战贴 boss，90 秒云铺满脚下仍会反复踩入）。
- **剩余承伤**：粉碎者包对全队 5 场 91 万（≈18 万/场，已超过酸液云），门怪 12 万→31 万（存活更久）；击杀用时 476 秒，540 秒时限对这一形态偏紧。
- 结论：躲 AoE 是必要且明显的改善（0/5→1/5，boss 最低血量未整体改善），不足以稳定通关；下一杠杆候选为粉碎者阶段承伤与整体战斗时长。
