## 机制

- raidtest `DungeonRun = 1`：入口开 attempt，坦克开 playerbots `dungeon run`，其余人以坦克为主人跟随；框架只观察
  （每 5 秒 `route_progress`，8 分钟无进度判卡住）。完成判据 `KillOnInstanceData = 2:3`：本副本实例脚本只用 SetData
  记遭遇进度，`KillOnBossState` 永远判不到。
- 路线 `mod-playerbots data/dungeon-routes/574-utgarde-keep.route`，由 `tools/route-gen` 生成 + `overrides/574-utgarde-keep.txt` 人工修正。
- 卡住排查：`Playerbots.log` 里 grep `dungeon-run bot=`（pull / waiting / skip / approach / route cleared）与 `floor-guard`。
