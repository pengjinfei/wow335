## 2026-09-29 修复：掉落与打茧

**掉落的真实机制。** raidtest 新增只读 `fall_detect`（`2613eab`）：一秒内降 >4 码时记录发起动作、请求点、spline 终点，首样本重放 PathGenerator。2 场基线 208 个下坠样本中 202 个来自 `rear flank`：请求点 z=298.8 是**迈克斯纳自身的 z，她陷在蛛网面（≈302）下 3 码**；核心给玩家 spline 终点纠 z（`UpdateAllowedPositionZ` → `GetWaterOrGroundLevel`）只从 z+2 码往下搜，漏掉蛛网、落到 140 码下的坑底 158.6，bot 沿 spline 以跑速走穿地板。站过去的 bot 自身也陷在面下，从 bot z+碰撞高度再搜同样会漏。

**修法（共享层 `MovementAction::LiftSunkenDestination`）。** 30 码内短移动：按核心同一探针（z+2）落差 >6 码时，从 max(目标 z, bot z)+5 再搜，结果与 bot 同层（±6 码）才把终点抬上去。两个不成功的尝试：只在下发后读 movespline 检查终点（施法中/变速时 spline 在 DoUpdate 里重建，读不到）；用碰撞高度而非核心的固定 2 码当探针偏移（碰撞高 3.17 的 bot 能搜到、核心搜不到）。效果：下坠样本 ~100/场 → 0（剩余都是正常下坡），仅此一项 1706–1708 为 2/3。

**打茧 ping-pong。** 实验规则里远程"打茧"能切到茧，但下一 tick 目标已是茧、动作无事可做，下一个动作 `dps assist` 又切回 boss——茧只在两次切换之间挨打，有人被连缠 58 秒（1714 茧杀 5 人）。`MaexxnaGenericMultiplier`：当前目标是活着的茧时 `dps assist` 乘 0。之后茧约 4 秒破。
