- **路线生成**：86 条 1 级中立「毒牙蝮蛇」（faction 7）被当成一组怪，领队空拉三次后去拉 Slad'ran（2142）——routegen 跳过 faction 7/190；
  竞技场三只骑手犀牛是载具（npcflag spellclick），原先被跳过，现保留。
- **入口走廊**：三组蛇各自成组，彼此 22 码内。第一组从旋梯脚 (1830,632) 拉（只有那里看得见），队伍在旋梯 (1846,643) 等（2151 三组 9 精英同时上）；
  第二组从走廊 (1808,634) 拉（2165 走到跟前把第三组也带上）；第三组在 Slad'ran 楼梯南、正在他的等候点上，排在他之前、从东侧平地 (1790,632) 拉
  （2146 没清；2148 沿骨架走上楼梯离 Slad'ran 13 码，一起拉了）。
- **斯拉德兰**：按隔离战（ilvl 200 档 10/10）打法，队伍在楼梯南 (1775,621) 等、坦克上台拉。2142 在缠绕蛇刷新点上五人挤 5 码内，打到 8% 灭。
- **西厅**：Lancer + 火焰编织者巡逻 (1696,637)↔(1634,680)，东端离第一组 4 码，穿过眼镜蛇组的环线。第一组等巡逻离开 40 码再拉（`clear=127045:40`，2176）；
  巡逻在东端时从走廊拉；眼镜蛇组在环线东侧时拉（2143）。
- **巨像**：冻结不可攻击，玩家打到他召唤的活体魔精才开战（脚本 `JustEngagedWith` → `ACTION_INFORM`）；领队等了 7 分钟（2153）。共享层改为打 boss 召唤的可攻击怪。

## 共享层与核心（本轮）

- 核心 `PathGenerator::NormalizePath`：贴地后比导航网格低 4 码以上的路径点保留网格高度（vmap 缺地板时贴到地形 z 0 或地板下 8–9 码，2145、2179）。
- 核心 `instance_gundrak`：艾克召唤检查按 guid 重取遗迹居民（原裸指针在 1 秒内被释放即崩溃，检查点夹具必现）。
- playerbots 重力：脚下没有碰撞地板（只剩地形）、或站着的 bot 脚下是 30 码以上且没有水的深洞时，旁边 2 码内的网格算地面，
  上下 12 码内的网格走回去（2150、2157、2167、2174；魔枢 Telestra 后的洞 2193）。有水的洞照常下落（Hadronox 竖井，2198 曾被拦住）。
- playerbots 领队：boss 不可攻击时打它 40 码内召唤的可攻击怪；新路线条目 `cross`。

- raidtest 名单：每次组队清掉背包里旧掉落（保留补给）；同一组角色跑十几把后背包满，坦克在巨像房间循环拾取卡住（2203）。
