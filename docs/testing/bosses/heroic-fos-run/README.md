## 打法与修正

- **入口大厅**：中间是深渊，第一对守卫前的停步点落在深渊上空，坦克沿直线走进半空掉下去（2206）——共享层：停步点路径不是导航网格路径时向怪组挪。
- **坡道上 Bronjahm 前的四只灵魂守卫**（Reaper×2 人形、Adept 人形、Bonecaster 亡灵）：
  - 原先 FoS 策略没继承小怪控制链，四只同时上、伤害被 AoE 平摊，连灭（2218–2220）——策略改继承 `TrashCcPullStrategy`。
  - 变羊只分给 30 码内的目标，等候点在 50 码外时只分到闷棍（2224）——等候点挪到拉怪点 (5222,2395) 旁。2237 起零死亡通过。
  - 走向它们时停步点被拒、站 75 秒后跳过、穿怪去 Bronjahm（2218）——拉怪点 (5222,2395)，四只里三只在视线内。
- **Bronjahm**：
  - 策略原来在他在场时一律禁止坦克自动选目标，整本里坦克没目标，整场只打 1.5k（2213、2214）——只在目标已是他时禁止。
  - 平台旁 50–60 码的两只哨兵、两组噩梦+活化者原为旁路，打他时被引来（2237）——改为必清、排在他之前。2240、2242 验证通过。
- **Devourer**：2212、2209 打过，暂无问题。
