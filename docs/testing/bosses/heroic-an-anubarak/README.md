## 死因（量化，attempt 2）

坦克生命上限 **22,784**（roster 快照）。a2 逐次承伤：

| 时刻 | 伤害 | 累计 | 若无治疗的剩余血 |
|---|---|---|---|
| 4.6 秒 | 2,785 | 2,785 | 19,999 |
| 6.6 秒 | 2,625 | 5,410 | 17,374 |
| 14.8 秒 | 2,310 | 7,720 | 15,064 |
| 16.8 秒 | 1,806 | 9,588 | 13,196 |
| 17.4 秒 | 91（甲虫） | 9,679 | 13,105 |
| **22.5 秒** | **16,087（践踏）** | 25,766 | **死** |

践踏一下 = 坦克 **70.6%** 的血量上限。它不是问题本身——问题是**它落下时坦克只剩约 13k**。

戒律牧师 a2 前 22.5 秒的全部施法：

```
1.7s 48074 耐力祷言(团队buff)   3.8s 48168 心灵之火(自buff)
6.4s 5019  魔杖射击 boss        7.3s 48066 真言术:盾 -> 坦克
8.7s 48111/41637/48113 愈合祈祷 -> 坦克
10.1s 48170 暗影防护祷言(团队buff)
18.4s 48162 耐力祷言(团队buff)
22.6s 48068 恢复 -> 萨满（坦克已死）
```

**对坦克的最后一个动作在 8.7 秒。** 之后到践踏落地的 13.8 秒里，牧师只放了两个团队 buff，
零直接治疗（无快速治疗 48071、无苦修 53007/47757）。

与同一牧师、同一装备档、同日 run426（魔枢凯利丝塔萨，**125.7 秒零死亡击杀**）对照：

| 法术 | run426（126 秒） | run430 各场（55–87 秒） |
|---|---|---|
| 真言术：盾 48066 | **19** | 2–4 |
| 苦修 53007 | 3 | 0–2 |
| 恢复 48068 | 4 | 0–1 |
| 魔杖射击 5019 | 2 | 1–4 |

归一后 0.15 次盾/秒 vs 0.04 —— 差近 4 倍。run426 前 20 秒牧师有连续 2 秒节拍的输出与 4 次盾；
run430 同期是 4 次团队 buff + 1 次盾，10.1–14.8 秒、14.8–18.4 秒、18.4–22.6 秒三段完全空转。

> 口径说明：事件表没有治疗量字段，「剩余血」是按承伤反推的**上界估计**（7.3 秒那个盾会吸收一部分）。
> 但「13.8 秒窗口内对坦克零直接治疗」是施法记录的直接事实，不依赖估算。

**结论**：死因是**开场 GCD 分配**——牧师在 boss 战里补团队 buff，而不是把坦克顶起来。
修复方向在 mod-playerbots（战斗中不该抢 GCD 放 1 小时团队 buff；或把 buff 移到开怪前的非战斗阶段）。
先量出「buff 为什么在战斗中才补」再动手，不要直接屏蔽 buff 动作。
