## 恐惧：量过了，不是判别量

用户指定先量恐惧结界(6346)/战栗图腾(8143)。两场（其中一场是完整 107 秒战斗、6614 条 PUSH）的
Playerbots.log 里，**`fear ward` 和 `tremor` 出现 0 次**——连触发器都没亮过。根因是结构性的：

| 职业 | 技能学了吗 | 引擎里有动作吗 | 有策略推它吗 |
|---|---|---|---|
| 牧师 | ✅ 6346 在 `character_spell` | ✅ `FearWardTrigger` / `CastFearWardAction`（`PriestActions.h:156`） | ❌ **没有**。全仓只有 BWL 奈法利安 / TK / 海加尔三个团本脚本显式 `CastSpell("fear ward")` |
| 萨满 | ✅ 8143 | ✅ `CastTremorTotemAction`、`EarthTotemStrategy`（getName = `"tremor"`） | ❌ 土图腾槽默认不是 `tremor`；实测跑的是 `stoneskin totem` |

**但恐惧不是这个 boss 打不过的原因**（run 560 五场）：

| | 输出总量 | 迅猛龙(26641)造成的伤害 | 恐惧 casts | 死亡 |
|---|---|---|---|---|
| a3 kill | 621,980 | **39,536** | 6 | 0 |
| a4 kill | 629,710 | **19,682** | 6 | 0 |
| a5 kill | 628,300 | **14,304** | 6 | 0 |
| a1 wipe | 457,748 | **74,090** | 6 | 6 |
| a2 wipe | 498,167 | **71,586** | 7 | 6 |

恐惧次数与时间点在击杀场和团灭场**完全一致**，而三场零死亡的击杀同样吃满了恐惧。
真正分开两类的是迅猛龙的存活时间（承伤差 3–5 倍）和随之而来的输出差（27%）。
**结论：反恐惧（恐惧结界/战栗图腾/无敌）留到有证据的时候再做，不是这一轮的靶子。**

## 量目标切换链 → 量到的是「治疗被视线饿死」（2026-09-16 下午，run 560 五场）

用户指定量目标切换链。量下来**目标切换不是问题，链条要往前推三步**：

**第一步：迅猛龙一只都没被打死。** Raptor Call 拽来的两只（26641）在 run 559+560 **十场里一次都没死**，
死亡记录里只有开怪前清掉的那只前置怪。但它们在击杀场只打出 14k–40k、团灭场 72k–74k——
差别不在"杀得快不快"，在别处。

**第二步：boss 在坦克活着时从来没打过非坦克。**

| | 迅猛龙打谁 | boss 打谁 |
|---|---|---|
| 三场击杀 | **只有坦克** | **只有坦克** |
| 两场团灭 | 坦克 23k/35k、牧师 24k/16k、法师/萨满/盗贼 | 坦克 28k/42k、法师 10k/30k、其余若干 |

两场团灭 boss 首次打非坦分别在 72s / 70s，而**坦克阵亡在 69s / 68s**——转火是坦克死后的结果，
不是原因。仇恨没问题。

**第三步：坦克死是因为治疗停了。** run 560 / a1 是教科书级的一段：

```
50–69s  治疗 hp=14270/14270（满血）  pos 固定在 (-557.00,-687.61) 一动不动
        casting=5019（法杖平A）      法力 13712 → 15170（在回蓝，说明没施法）
        同期坦克 10206 → 0
        两人相距 17–19 码，raidtest los 实测 **los=false**（中间有柱子）
```

**把「无视线秒」按因格瓦尔那轮的口径量全场**（每秒一采样，已剔除死后采样）：

| attempt | 结果 | 有视线秒 / 治疗次数 / 每秒 | 无视线秒 / 治疗次数 / 每秒 |
|---|---|---|---|
| a1 | wipe | 26s / 10 / **0.38** | 22s / 1 / **0.05** |
| a2 | wipe | 30s / 8 / 0.27 | 19s / 6 / 0.32 |
| a3 | kill | 48s / 21 / **0.44** | 27s / 2 / **0.07** |
| a4 | kill | 72s / 40 / 0.56 | 2s / 0 / — |
| a5 | kill | 77s / 33 / 0.43 | 0s / 0 / — |
| **合计** | | **253s / 112 / 0.44** | **70s / 9 / 0.13** |

**有视线 0.44 次/秒，无视线 0.13 次/秒，掉 70%。** a1 的 22 秒无视线块直接压在坦克死前；
a3 是同样的机制但 boss 先死了（坦克在块内掉到 2526 血险些团灭）。

**这正是 [LESSONS](../../LESSONS.md) 里排第 0 条、标着「未修」的共享层缺陷**：
`PartyMemberValue::Check` / `PartyMemberToHeal::Check` 硬性要求 `IsWithinLOS`，
视线断掉时治疗目标列表直接为空 → 不治；而所有"走过去"的动作又都以同一个值为目标 →
连挪一步都不会。因格瓦尔那轮只在 UK boss 层做了 `ingvar regain los` 侧移，**共享层版本至今没做**。
德雷德这个房间有柱子、坦克又要追着迅猛龙跑，于是稳定复现。

**a2 是另一种死法，别混为一谈**：它的治疗全程有蓝（10–13k，末尾的 0 是死后采样伪影）、
无视线秒里照样在治（0.32/s），但坦克 68 秒里挨了 76k ≈ 1.1k/s，而治疗量跟不上。
候选机制是 Grievous Bite(48920) 的叠加受疗降低（a2 在 35/64/84 秒各一次）——**尚未量**。

**下一步（需要用户决定）**：做共享层的视线修复（给接近动作喂一个不按视线过滤的取值，
施法仍用带视线的那个），影响所有治疗职业，必须回归三个旧 boss。

## 共享层视线修复：无视线占比 22% → 3%，击杀 3/5 → 15/16（2026-09-16 傍晚，mod-playerbots `9134211d`）

## 第二条共享层修复：`main tank` 不再按视线过滤（2026-09-16 夜，mod-playerbots `5ef5adcc`）

治疗那条修完后又量了同族的第二条。`PartyMemberMainTankValue` 用的是基类
`PartyMemberValue::Check`（带 `IsWithinLOS`），坦克被柱子挡住那一秒 `main tank` 返回空，
所有 `if (!mainTank) return false;` 的行为**整组静默跳过**（引擎日志里连 PUSH 行都没有）：

**先量后改**（mod-raidtest `9d36278` 新增只读探针 `mt=`，每秒记该 bot 能否解出 main tank；

## 场景设计与三次翻车（**别重走**）

最终配置：准备点 (-500,-735,30.3)、开怪点 (-536,-690,30.3)、
`PrerequisiteSpawns = 127454`、`FixtureDespawnSpawns = 127452,127413,127414,127415,127453,127455`。

1. **run 552**：前置列了四只迅猛龙。清完东南两只后队伍北上打 127453，路径必然穿过 boss 的
   22 码仇恨半径 → 61 秒 boss 自己进战斗，`prerequisite_invalid: boss engaged before clearing`。
   **北边那两只在不进仇恨半径的前提下够不着。**
2. **run 554**：前置收到两只、清怪 35–40 秒成功，但开怪被拒：
   `pull_rejected ... los=false`，boss 位置 (-539.2,-668.7)——**德雷德会巡逻**，
   出生点 (-544.9,-697) 只是他路过的位置。开怪点换成对整条巡逻线都有视线的 **(-536,-690)**
   （对 (-544.9,-697)/(-539.2,-668.7)/(-541,-710)/(-535,-655) 四点实测全 los=true）。
3. **run 556**：五场全部 `prerequisite_invalid: boss entered combat during recovery`——
   清完怪后队伍就站在他巡逻线旁边（127413 距他巡逻点只有 17 码），恢复窗口里他自己走过来。
   → 前置只留最东边的 127454（距巡逻线 ≥25 码），其余六只在 pull 那一刻由夹具移除。

**为什么必须留一只前置**：框架里只有走过「前置清怪 → 恢复」这条路，恢复结束时才会
把队伍**传送**到开怪点（`AttemptRunner.cpp` 的 Recovery → BossPosition）。没有前置怪的场景，
队伍会停在准备点开怪；而这里准备点离 boss 58.8 码，根本开不了。**这条对以后每个
「准备点必须远离 boss」的新场景都成立。**

口径：**隔离 boss 战（夹具移除六只迅猛龙）**。真人打法本来也是先把房间清光再拉 boss，
所以夹具移除与「已清完」在效果上等价；但结论仍按隔离形态记账。
