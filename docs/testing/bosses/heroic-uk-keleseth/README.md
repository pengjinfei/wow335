#### attempt 1 的 abort 不是策略失败：框架恢复门禁 + bot 不喝水

attempt 1 记的是 `prerequisite_failed: natural recovery timeout`，boss 从未参战
（`boss_hp_min=100`）、零死亡。`AttemptRunner` 的 Recovery 阶段要求每名成员在 **120 秒内**
同时达到 `mediumHealth`（65%）血量**和** 65% 法力，期间框架不恢复任何资源。四只英雄小怪
打完后戒律牧只剩 **1,989/16,708 = 11.9% 法力**，此后每 15 秒恒定回 ~1,180 点（≈78/s，
纯精神回蓝），151 秒才回到 10,242（61%），门禁在 120 秒判负：

| 恢复用时 | 牧师法力 |
|---:|---:|
| 46s | 1,989/16,708 |
| 76s | 4,338 |
| 106s | 6,700 |
| 136s | 9,071 |
| 151s | 10,242（仍 < 65%） |

回蓝曲线全程是一条直线，**没有任何喝水的加速段**——而牧师包里有 20 个蜜风茶（33445）
与 20 份食物（33443），`UseFoodStrategy` 在无 food cheat 时正是用 `low mana` 触发器接
`drink` 动作，`AiPlayerbot.LowMana = 15` 而它当时是 11.9%。也就是说**低于喝水阈值仍然
没喝**。attempt 2–5 只是因为清怪耗蓝较少（残余 9.5k–10.6k）才踩过门禁，同一条件下会
随机复现。

两条待办分层清楚：

1. **mod-playerbots（真实缺陷，优先）**：战斗外低于 `LowMana` 阈值时不进食/喝水。
   五人本连打时它直接决定下一场能不能开，前置怪越多越严重。
2. **mod-raidtest（门禁口径）**：120 秒的自然恢复预算是按英雄档法力池定的；在证实
   喝水行为修好之前，普通档可能需要更长预算。不得用框架补资源来绕过。
