设计：[08-整本通关与AI带队](../../../08-整本通关与AI带队-设计.md)。第三个整本通关副本。

**2026-09-30：整本通关，v17 4/4**（run 1885–1888，19–22 分钟；首通 run 1879），含从哈多诺克斯坑底跳进阿努巴拉克洞窟的水池。阵容 `heroic5gear-n5talents-v2`（ilvl 200 档）。

## 机制

- 路线 `mod-playerbots data/dungeon-routes/601-azjol-nerub.route`：TravelNode 链 入口 → 希尔希克 → 克里克希尔 → 碾压者 → 哈多诺克斯（646 码骨架），
  之后没有 TravelNode 连接：从哈多诺克斯坑底网上的洞跳下 360 码，落进阿努巴拉克洞窟的水池（水面 288.5、池底 276，探针 `.raidtest los` 现报液面）。
- `tools/route-gen/overrides/601-azjol-nerub.txt`，本副本新增的路线能力：
  - `sent=1`：遭遇自己派来的怪组，领队原地（或 `hold=` 处）等，不去拉；240 秒不来才拉。克里克希尔一旦有守望者进战就按 60/120 秒、每组死后 5 秒派下一组，200 秒本人下场。
  - `summoned`：脚本召唤的怪组（spawnId 0），按 entry + 半径找；哈多诺克斯的碾压者包 1 站在 TravelNode 上。
  - `drop … rim=`：先走到洞沿，再全队直线迈出去，靠重力模拟下落；领队下去后把还在上面的队员推下来。
  - `hold=`：哈多诺克斯要在上层平台（530,580,733.9）等——她爬上来会织网封门；在坡道中段遇到时她不断杀通道里刷出的地穴魔（每只 +10% 血），91 万伤害打不死。
- 共享层随之修的：领队有战斗标记但无攻击者时照常推进；重力模拟落到水面而不是池底（池底待着会淹死）、陷进地面下时抬回地面。
- 完成判据 `KillOnBossState = 2`（阿努巴拉克）。
