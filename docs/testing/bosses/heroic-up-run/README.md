## 做过的修正

- **停步点必须在怪那一层的导航网格上**（共享层）：楼上走廊对楼下天灾巨兽的停步点落在楼上地板里，寻路给直线，坦克沉进地板被重力模拟摔到 z -176（100192）。与本机同类修正（灵魂洪炉 2206）合并。
- **入口无心仆从**不再主动去拉：停步点在走道外无地板处（100191）。
- **斯瓦拉、斯卡迪**拉怪点设在各自触发区域（5140、4991）：离触发区 26 码时剧情不开始（100196/100198）；斯卡迪在空中，往他走被拒（100194）。
- **戈托克**：四只冻结野兽不作为怪组；先清身边伊米亚尔，再点宝珠 188593。
- **下层走廊**：两只狂战士巡逻走遍走廊，先在东头拉东组（等巡逻离开），再在东端拉巡逻（100197）。

## 遗留

- 斯卡迪鱼叉分工：拿鱼叉、送到发射器都由输出职业单独穿过刷怪大道完成，被截杀就射不下格劳夫（BACKLOG 14）。
- 伊米隆偶发长战与团灭（100200、100206 打 7 分多钟、100208）。
