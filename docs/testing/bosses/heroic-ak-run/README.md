## 机制与路线

- 路线 `mod-playerbots data/dungeon-routes/619-ahnkahet.route`，覆盖 `tools/route-gen/overrides/619-ahnkahet.txt`：
  第一大厅巡逻 131901 与两组精英分开拉（`from=`/`hold=`）；走廊爬行者等巡逻走开；下层房间巡逻 131903 用 `split=1` 拆组；
  两个装置 `object`；纳多克斯旁平台怪组 `side=1`；暮光信徒区按组从坡下逐个拉；耶戈达开场入会者 `summoned` + boss 行。
- **塔达拉姆火球**（30106/31686/31687，59509 灼烧半径 ≥16 码）：生成后 3 秒，第一颗朝坦克位置走 25 码，另两颗 ±90°。
  playerbots `AKActions` 在三个候选点（第一颗去向后方 20 码、±45° 30 码）里选直线路径离生成点 ≥8 码的最近点；坦克/近战总躲，远程在路径上才躲。
  平台是游戏物体、不在导航网格上，躲避用直线 MovePoint。
- **耶戈达**：10 个暮光信徒 30111（火球 / 烈焰风暴）DPS 先杀。
- **阿曼尼塔**：坦克跳过不打人的被动单位（蘑菇）。

## 共享层（本轮合并，已回归）

停步拉怪对每个怪组成员校验距离、目标 z 不搜地面；拉怪点等待（60 秒）与拒绝后不拉；全队退守点（`hold=`，每 tick 重申 stay，领队开打即放）；
`cc=0`；可攻击判断（boss 活着但不可攻击不算清）；路径终点在地图下且无碰撞地面时拒绝；离网格时只直走到领队高度附近的地面；
空中节点跳过；视线外的尸体也去复活；`AiPlayerbot.AutoAvoidAoeWithoutMaster`（躲 AoE 从 raidtest 移到 playerbots 配置）。

回归（同二进制）：艾卓-尼鲁布 2011、2012 击杀；UK 2010 击杀（2008 卡在闸门 → 地图下拒绝条件收窄后修复）；魔枢 2006 击杀、2007 团灭在奥莫洛克前磨损者区（判断为波动）。
