## 四、下一个副本要用的东西

1. **先读 [LESSONS](LESSONS.md)**，尤其新加的三条口径陷阱（运行中的占位行、夹具只看房间里有谁、新动作的距离参数）。
2. **新场景清单**（这一轮四次踩坑换来的，逐条照做）：
   - `raidtest_accounts` 按 scenario_key 存槽位映射，**新场景键必须手工补一行**，否则框架去新建角色并因重名失败。
   - 场景**只在启动时注册**，新建/改 conf 都要重启 worldserver（约 6–7 分钟）；重启后第一条 FIFO 命令会被吞，**发完必须回读**。
   - **没有前置怪的场景，队伍停在准备点开怪**（框架只在「前置清怪 → 恢复」这条路的末尾把队伍传送到开怪点）。
     所以准备点必须远离 boss 的场景，**至少要留一只前置怪**。
   - boss 会巡逻时，开怪点要对**整条巡逻线**都有视线（`creature_addon.path_id` → `waypoint_data` 取全部航点逐点探）。
   - 建夹具要查巡逻（`MovementType=2`）与编队（`creature_formations`，groupAI≠0 拉一只等于拉一组）。
   - 连续跑 >5 场会撞 `AccountInstancesPerHour = 5`（`enter_reason=8`），`DELETE account_instance_times` 不总是立刻生效。
3. **待办第 0 条**（本轮明确放到后面）：给施法型取值（驱散/复活/团队 buff）补「走过去」链条。

德雷德的靶子换了三次，每次都是**量出来的**、不是想出来的：

   与坦克相距 17–19 码 `los=false` → 落到那条一直没修的共享层缺陷上。
