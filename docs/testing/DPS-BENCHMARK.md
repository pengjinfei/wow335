# 输出基准（木桩）

更新：2026-09-28。用来量各天赋的 DPS、技能构成和循环问题，作为循环 / 天赋 / 雕纹修改的前后对照。**不是遭遇战验收**。

## 方法

- 场景 `bench-dummy-h5g`（raidtest `conf/`）：紫罗兰监狱房间中央召一个 **Heroic Training Dummy（31146）**，83 级 boss 级别（与团本 boss 同等级），`npc_training_dummy` 不会死、不还手、5 秒不挨打就脱战。每场固定 180 秒，结果记 `timeout`。
- 木桩在 `DamageTaken` 里把伤害改成 0，而 raidtest 的 `OnDamage` 在它之后；raidtest `CombatEventBus` 在更早的 `DealDamage` 钩子里记原始伤害（只对木桩）。开怪时木桩没有仇恨目标，框架跳过「坦克拿到仇恨」的检查。
- 阵容：`heroic5gear-n5talents-v2`（v1 复制，只改刺杀贼大雕纹 破甲 → 饥渴之血）。防骑 / 戒律 / 刺杀贼 / 火法 / 元素萨，ilvl 200，无团队增益。
- 分析：`bench.py <run_id>`（scratchpad，按 bot 列 DPS、技能伤害占比、施法次数）；DPS = 对木桩的总伤害 / 首末伤害之间的秒数，不含宠物。
- **噪声**：同配置单职业场与场之间 ±5–8%（火法最大，暴击触发的热力迸发/点燃）。一个改动至少跑 2–3 场再比。

## 找到并修掉的循环问题

| 职业 | 问题 | 修法 | 效果 |
|---|---|---|---|
| 元素萨 | 闪电链「冷却好就放」（5.6）压过只是默认动作的熔岩爆裂（5.2），单体时熔岩爆裂只在闪电链冷却时才放 | 目标有自己的烈焰震击时熔岩爆裂 5.7；闪电链只在 2 个以上目标时优先 | 熔岩爆裂 12–13 → 16 次/180 秒，约 +12% |
| 元素萨 | 元素掌握等「1 级闪电链（421）冷却」才放；冷却按实际施放的等级记，永远不触发 | 战斗中、身上没有增益就放 | 0 → 1 次/场（收益在噪声内） |
| 刺杀贼 | 饥渴之血对敌人施放、增益（63848）在自己身上，旧逻辑去敌人身上找增益；且没人上流血 | 查自己的增益；**目标身上没有任何人的流血时**先上短割裂（有战士/野德等别人的流血就不用） | 饥渴之血从 0 → 每场保持 |
| 刺杀贼 | 切割和毒伤同优先级，永远被毒伤抢走 | 切割没挂时优先（有 Cut to the Chase，之后毒伤会续） | 切割从 0 → 每场保持 |
| 刺杀贼 | 破甲把终结技花在只有自己和坦克吃得到的减甲上 | **队里有其他非坦克物理输出时才上破甲** | 毒伤 9 → 15 次/场 |

天赋（playerbots 预设 `PremadeSpecLink`）核对过：刺杀 51/13/7、火焰 18/53/0、元素 57/14/0，都是标准点法，没改。

- 元素萨雕纹 火舌武器 → 熔岩：预期约 +2%，在噪声以内，未测。
