# 输出基准（木桩）

更新：2026-09-28。用来量各天赋的 DPS、技能构成和循环问题，作为循环 / 天赋 / 雕纹修改的前后对照。**不是遭遇战验收**。

## 方法

- 场景 `bench-dummy-h5g`（raidtest `conf/`）：紫罗兰监狱房间中央召一个 **Heroic Training Dummy（31146）**，83 级 boss 级别（与团本 boss 同等级），`npc_training_dummy` 不会死、不还手、5 秒不挨打就脱战。每场固定 180 秒，结果记 `timeout`。
- 木桩在 `DamageTaken` 里把伤害改成 0，而 raidtest 的 `OnDamage` 在它之后；raidtest `CombatEventBus` 在更早的 `DealDamage` 钩子里记原始伤害（只对木桩）。开怪时木桩没有仇恨目标，框架跳过「坦克拿到仇恨」的检查。
- 阵容：`heroic5gear-n5talents-v2`（v1 复制，只改刺杀贼大雕纹 破甲 → 饥渴之血）。防骑 / 戒律 / 刺杀贼 / 火法 / 元素萨，ilvl 200，无团队增益。
- 分析：`bench.py <run_id>`（scratchpad，按 bot 列 DPS、技能伤害占比、施法次数）；DPS = 对木桩的总伤害 / 首末伤害之间的秒数，不含宠物。
- **噪声**：同配置单职业场与场之间 ±5–8%（火法最大，暴击触发的热力迸发/点燃）。一个改动至少跑 2–3 场再比。

## 找到并修掉的循环问题

| 职业 | 问题 | 修法 | 效果 |
|---|---|---|---|
| 元素萨 | 闪电链「冷却好就放」（5.6）压过只是默认动作的熔岩爆裂（5.2），单体时熔岩爆裂只在闪电链冷却时才放 | 目标有自己的烈焰震击时熔岩爆裂 5.7；闪电链只在 2 个以上目标时优先 | 熔岩爆裂 12–13 → 16 次/180 秒，约 +12% |
| 元素萨 | 元素掌握等「1 级闪电链（421）冷却」才放；冷却按实际施放的等级记，永远不触发 | 战斗中、身上没有增益就放 | 0 → 1 次/场（收益在噪声内） |
| 刺杀贼 | 饥渴之血对敌人施放、增益（63848）在自己身上，旧逻辑去敌人身上找增益；且没人上流血 | 查自己的增益；**目标身上没有任何人的流血时**先上短割裂（有战士/野德等别人的流血就不用） | 饥渴之血从 0 → 每场保持 |
| 刺杀贼 | 切割和毒伤同优先级，永远被毒伤抢走 | 切割没挂时优先（有 Cut to the Chase，之后毒伤会续） | 切割从 0 → 每场保持 |
| 刺杀贼 | 破甲把终结技花在只有自己和坦克吃得到的减甲上 | **队里有其他非坦克物理输出时才上破甲** | 毒伤 9 → 15 次/场 |

| 元素/恢复萨 | 大地图腾写死石肤 | **队里有非坦克近战就放大地之力**（+155 力敏），否则石肤 | 贼 2904 → 3144（+8%）、坦克 +13% |

雕纹：刺杀贼 破甲 → 饥渴之血（v2）；元素萨 火舌武器 → 熔岩 试过更差（2889 → 2712），保留火舌武器。风怒 vs 空气之怒：近战 +10%、元素萨 -17%，全队持平，保留空气之怒（还能给治疗急速）。

天赋（playerbots 预设 `PremadeSpecLink`）核对过：刺杀 51/13/7、火焰 18/53/0、元素 57/14/0，都是标准点法，没改。

## 10 人阵容（`raid10-ilvl200-v1`，2026-09-28）

场景 `bench-dummy-raid10`：纳克萨玛斯入口传送平台（map 533）。平台中央传送台和四个落点的拱门挡视线，第一版（run 1526）近战绕不过去、DK/贼/防骑几乎零输出；用 `raidtest los` 扫出平台上视线通的点对后，准备点放东北斜角距中心 6 码（3009.9,-3430.2），木桩在同方向再 8 码（3015.6,-3424.5）。

阵容：防骑 / 血 DK（坦）、戒律 / 神圣骑（疗）、刺杀贼、火法、元素萨、毁灭术、平衡德、生存猎。补齐时顺手修了 raidtest 的几个缺口：跟随者传送漏掉副坦（5 人本只有一个坦克看不出来）、DK 没有死亡之门被 `TeleportTo` 留在阿彻鲁斯、弹药不算补给、雕纹槽位类型顺序必须 大小小大小大、元素/坚韧多彩宝石的激活颜色。

治疗在木桩上没人掉血，只打审判/射击，不看。团队增益（大地之力、月蚀、野性印记、真言术：韧、智慧审判等）都在，比 5 人阵容每人高 10–20%。

**小队分配不影响增益**：3.3.5 的图腾、枭兽光环、强击光环、兽群领袖、圣骑士光环、憎恶之力在 DBC 里都是 `APPLY_AREA_AURA_RAID`（65），全团生效，只受半径限制（空气之怒/大地之力/法力之泉 30 码，天怒图腾 40 码）。按「图腾只给本小队」重排后术士的施法间隔与重排前完全相同（烧尽 1.8 秒 / 逆火 1.2 秒），本来就吃到空气之怒；重排撤回。远程在木桩上都站在准备点同一格，离萨满 0 码。

**重复的增益**：寒冬号角（DK，全团）= 大地之力，所以团里有 DK 时萨满改放石肤（`dad73387`，贼输出不变，坦克多护甲）；枭兽光环 = 元素誓言（都 +5% 法术暴击），两者只算一份；灵魂汲取（毁灭术）与狩猎聚会（生存猎）的回复各自都能覆盖全团。换职业能消除重复，但用户决定阵容不变（破甲 / 流血由贼负责）。

逐职业核对：

- **血 DK**：默认填充里冰冷触摸（冰霜符文）排在心脏打击前，灵界打击只在两个邪恶符文都好时才打——冰霜符文先被冰冷触摸吃光。改为符文打击 > 灵界打击 > 心脏打击，冰冷触摸只由「缺疾病」触发器上、之后靠传染续。1027 → 1177（+15%），灵界打击 14 → 29（自疗）。副作用：冰爪（冰霜疫病挂上时的自身急速）覆盖变低（41 → 9 次），净效果仍正。
- **毁灭术**：献祭 / 燃烧 / 混乱之箭按冷却、烧尽填充，生命分流有雕纹。开场上一次元素诅咒（5 分钟）；与鸟德的月蚀同类不叠，按搭配改痛苦诅咒约 +160 dps（< 1% 全队），**记下没改**。
- **平衡德**：愤怒 / 星火按月蚀切换，虫群 / 月火保持，星辰坠落按冷却。没发现问题。
- **生存猎**：爆炸射击（含荷枪实弹）、黑箭、毒蛇钉刺、杀戮命令 / 急速射击按冷却；蝰蛇守护是低于 7% 蓝时开、60% 回切（每场 15 次回蓝触发，第一版 43 次是近战卡位那场）。宠物是随机驯服的野猪，宠物伤害不计入；换狼（狂怒之嚎）属于小项，没做。
- 刺杀贼 / 火法 / 元素萨 / 防骑同 5 人阵容的结论（上文），只是团队增益更全。

## 还没做 / 边际收益

- 爆发技能对 boss 生效（BACKLOG #22）：**木桩测不出**——木桩 rank 3 按 ×20 加权，原逻辑 `balance` 就 ≤50%，爆发本来会放；第 4 行的差异是噪声（刺杀贼的爆发属战斗天赋，不受影响）。
- 火法循环没发现问题（火球 44 次、活动炸弹 13 次、热力迸发触发即放、强化灼烧常驻、燃烧/镜像都在用）。
- 全队木桩 DPS 约 9600 → 10420（+8.5%）；贼、元素萨、火法在木桩上已接近边际收益；剩下的差距在真实战斗里的走位/停手时间，木桩量不出来。
