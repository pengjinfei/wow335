# B2-3 位置采样增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 mod-raidtest 框架能记录每次 attempt 中 bot 与 boss 的**位置快照**，用数据回答"站位机制是否生效"（验证 Loatheb/其他 boss 的站位动作是否让 bot 站到正确位置）。

**Architecture:** 纯框架观察增强——在 `AttemptObserver::Tick`（每世界 tick 调用）中，按固定采样间隔（默认 1s）把每个 raid bot 与 boss 的坐标推入 `CombatEventBus`，事件类型用现成的 `State`（ShouldKeep 对 State 恒返回 true，语义由调用方负责），坐标编码进 `detail` 字符串。不涉及任何 bot 行为逻辑，符合框架边界原则。

**Tech Stack:** C++20（mod-raidtest）、`CombatEventBus::Push`、`raidtest_events` 表（`State` 类型已在 enum，无需改表）。

## Global Constraints

- 零核心/零 mod-playerbots 改动；只改 mod-raidtest。
- 纯观察：不改 bot 行为、不改站位逻辑、不改战斗判定。
- `raidtest` logger tag；世界线程非阻塞（采样在 Tick 内轻量执行，无 sleep/DB）。
- 编译已授权整个实现期；`MTHREADS=4` + ccache。
- 事件量控制：10 bot + 1 boss，1s 采样间隔 → ~11 events/s/attempt，可接受。

- [ ] **Step 2: Tick 内加采样逻辑**

`src/Observer/AttemptObserver.cpp` 在 boss 血量采样后加：
```cpp
    // ---- 位置采样（B2-3）：每 kPositionSampleMs 记录全队 + boss 坐标 ----
    if (ctx.attemptElapsedMs - _lastPositionSampleMs >= kPositionSampleMs)
    {
        _lastPositionSampleMs = ctx.attemptElapsedMs;
        for (Player* member : ctx.bots)
        {
            if (!member || !member->IsInWorld())
                continue;
            CombatEvent pos;
            pos.type = CombatEventType::State;
            pos.source = member->GetGUID();
            pos.value = static_cast<int32>(member->GetMapId());
            pos.detail = Acore::StringFormat("pos:{:.2f},{:.2f},{:.2f}",
                member->GetPositionX(), member->GetPositionY(), member->GetPositionZ());
            CombatEventBus::instance().Push(pos);
        }
        if (ctx.boss && ctx.boss->IsInWorld())
        {
            CombatEvent bossPos;
            bossPos.type = CombatEventType::State;
            bossPos.source = ctx.boss->GetGUID();
            bossPos.actorEntry = ctx.scenario ? ctx.scenario->GetBossEntry() : 0;
            bossPos.value = static_cast<int32>(ctx.boss->GetMapId());
            bossPos.detail = Acore::StringFormat("pos:{:.2f},{:.2f},{:.2f}",
                ctx.boss->GetPositionX(), ctx.boss->GetPositionY(), ctx.boss->GetPositionZ());
            CombatEventBus::instance().Push(bossPos);
        }
    }
```
> 需确认 `Acore::StringFormat` 可用（搜索模块里既有用法，如 notes 拼接）；若不可用用 `std::ostringstream`。`_lastPositionSampleMs` 在 AttemptObserver 加成员（Tick 开头用 0 初始化——需在 attempt 开始时重置，确认现有成员初始化方式）。
